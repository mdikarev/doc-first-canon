> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a local BM25-style index over `docs/canon/**` with per-doc content hashes, incremental updates, and `doc-canon index` (including `--watch`).

**Architecture:** Hash-manifest + serialized BM25 postings live under `.doc-canon/`. One-shot and watcher modes call the same sync path: compare hashes, remove/re-add only changed documents. Retrieval/`search` is **out of scope** here — see companion plan `docs/superpowers/plans/2026-08-11-retrieval-search-pack.md`.

**Tech Stack:** TypeScript (Node ≥20, ESM), `node:test` via `tsx`, `commander`, Node `crypto` + `fs.watch` (no new runtime deps unless tests prove `fs.watch` unusable on CI).

```typescript
// src/index/hash.ts
import { createHash } from "node:crypto";

export function contentHash(content: string): string {
  const hex = createHash("sha256").update(content, "utf8").digest("hex");
  return `sha256:${hex}`;
}
```

```typescript
// src/index/tokenize.ts
export function tokenize(text: string): string[] {
  return text
    .toLowerCase()
    .split(/[^a-z0-9]+/)
    .filter((t) => t.length > 0);
}
```

### Task 4: Bm25Index core (add / remove / score / serialize)

**Files:**
- Create: `src/index/types.ts`, `src/index/bm25.ts`
- Test: `tests/index-bm25.test.ts`

**Interfaces:**
- Consumes: `tokenize`
- Produces:
  - Types in `types.ts`:
    - `IndexDocMeta = { hash: string; token_count: number }`
    - `IndexManifest = { schema_version: 1; built_at: string; corpus: "docs/canon/**"; docs: Record<string, IndexDocMeta> }`
    - `Bm25State` — serializable postings shape used by `Bm25Index.toJSON` / `fromJSON`
  - `class Bm25Index`:
    - `static empty(): Bm25Index`
    - `static fromJSON(state: Bm25State): Bm25Index`
    - `toJSON(): Bm25State`
    - `upsertDocument(path: string, text: string): void` — remove if present, then add
    - `removeDocument(path: string): void`
    - `hasDocument(path: string): boolean`
    - `documentCount(): number`
    - `score(query: string): Array<{ path: string; score: number }>` — BM25 Okapi; k1=1.2, b=0.75; sorted desc by score; omit zero scores

**BM25 formula (document this in a short comment in `bm25.ts`):**

For each query term `t` in doc `d`:  
`idf(t) * (tf * (k1+1)) / (tf + k1 * (1 - b + b * |d|/avgdl))`  
where `idf(t) = ln(1 + (N - df + 0.5) / (df + 0.5))`.

Incremental correctness: `removeDocument` must decrement df for each unique term that was in the doc and remove postings; `upsertDocument` always remove-then-add.

```typescript
// tests/index-sync.test.ts
import assert from "node:assert/strict";
import { mkdirSync, mkdtempSync, readFileSync, rmSync, writeFileSync } from "node:fs";
import { tmpdir } from "node:os";
import { join } from "node:path";
import { describe, it } from "node:test";
import { syncCanonIndex } from "../src/index/sync.js";
import { bm25IndexPath, indexManifestPath } from "../src/index/paths.js";
import { Bm25Index } from "../src/index/bm25.js";
import { loadIndexBundle } from "../src/index/io.js";

function tempRoot(): { root: string; cleanup: () => void } {
  const root = mkdtempSync(join(tmpdir(), "doc-canon-index-"));
  mkdirSync(join(root, "docs", "canon"), { recursive: true });
  return { root, cleanup: () => rmSync(root, { recursive: true, force: true }) };
}

describe("syncCanonIndex", () => {
  it("builds artifacts and only reindexes changed files on second sync", async () => {
    const { root, cleanup } = tempRoot();
    try {
      writeFileSync(join(root, "docs", "canon", "a.md"), "alpha beta", "utf8");
      writeFileSync(join(root, "docs", "canon", "b.md"), "gamma", "utf8");
      const first = await syncCanonIndex(root);
      assert.deepEqual(new Set(first.updated), new Set(["docs/canon/a.md", "docs/canon/b.md"]));
      assert.equal(first.removed.length, 0);

      const second = await syncCanonIndex(root);
      assert.deepEqual(second.updated, []);
      assert.equal(second.unchanged, 2);

      writeFileSync(join(root, "docs", "canon", "a.md"), "alpha zeta", "utf8");
      const third = await syncCanonIndex(root);
      assert.deepEqual(third.updated, ["docs/canon/a.md"]);

      const { index } = loadIndexBundle(root);
      assert.equal(index.score("zeta")[0]?.path, "docs/canon/a.md");
      assert.ok(readFileSync(indexManifestPath(root), "utf8").includes("sha256:"));
      assert.ok(readFileSync(bm25IndexPath(root), "utf8").length > 2);
    } finally {
      cleanup();
    }
  });

  it("removes deleted documents from the index", async () => {
    const { root, cleanup } = tempRoot();
    try {
      writeFileSync(join(root, "docs", "canon", "a.md"), "alpha", "utf8");
      await syncCanonIndex(root);
      rmSync(join(root, "docs", "canon", "a.md"));
      const result = await syncCanonIndex(root);
      assert.deepEqual(result.removed, ["docs/canon/a.md"]);
      const { index } = loadIndexBundle(root);
      assert.equal(index.documentCount(), 0);
    } finally {
      cleanup();
    }
  });
});
```
