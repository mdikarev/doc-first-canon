# P0b BM25 Index Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a local BM25 index over `docs/canon/**` with content-hash freshness, logical full rebuild on any change, poll-based `--watch` / `--stop`, and a public `openCanonIndex` facade for P1.

**Architecture:** Each sync reads and hashes the full corpus. Unchanged hashes → no artifact rewrite. Any create/update/delete → rebuild BM25 from all current docs, write `bm25-index.json` then `index-manifest.json` (shared `index_id`, tmp+rename). Watch is a foreground poll loop with a pid lock. P1 imports `doc-canon/index-reader`, not raw postings JSON.

**Tech Stack:** TypeScript (Node ≥20, ESM), `node:test` via `tsx`, `commander`, `node:crypto` (`createHash`, `randomUUID`). No new runtime dependencies.

- Spec SoT: `docs/superpowers/specs/2026-08-11-p0b-bm25-index-design.md`. Split design is boundary-only; on P0b detail conflict, this plan follows the P0b detailed spec.

```typescript
import { createHash } from "node:crypto";

export function contentHash(content: string): string {
  const hex = createHash("sha256").update(content, "utf8").digest("hex");

}
```

```typescript
// src/index/list.ts
import fs from "node:fs";
import path from "node:path";
import { canonDir } from "../paths.js";

function walkMd(absDir: string, root: string, out: string[]): void {
  for (const ent of fs.readdirSync(absDir, { withFileTypes: true })) {
    const abs = path.join(absDir, ent.name);
    if (ent.isDirectory()) {
      walkMd(abs, root, out);
      continue;
    }
    if (ent.isFile() && ent.name.endsWith(".md")) {
      const rel = path.relative(root, abs).split(path.sep).join("/");
      out.push(rel);
    }
  }
}

export function listCanonMarkdown(root: string): string[] {
  const dir = canonDir(root);
  if (!fs.existsSync(dir)) {
    throw new Error(`docs/canon not found under ${root}`);
  }
  const out: string[] = [];
  walkMd(dir, root, out);
  out.sort((a, b) => (a < b ? -1 : a > b ? 1 : 0));
  return out;
}
```

### Task 5: Bm25Index (build-from-docs, score, serialize)

**Files:**
- Create: `src/index/types.ts`, `src/index/bm25.ts`
- Test: `tests/index-bm25.test.ts`

**Interfaces:**
- Consumes: `tokenize`
- Produces:
  - `IndexDocMeta = { hash: string; token_count: number }`
  - `IndexManifest = { schema_version: 1; index_id: string; built_at: string; corpus: "docs/canon/**"; docs: Record<string, IndexDocMeta> }`
  - `Bm25State = { schema_version: 1; index_id: string; postings: Record<string, Record<string, number>>; doc_lengths: Record<string, number> }`
  - `class Bm25Index`:
    - `static build(docs: Array<{ path: string; text: string }>, indexId: string): Bm25Index`
    - `static fromJSON(state: Bm25State): Bm25Index`
    - `toJSON(): Bm25State`
    - `documentCount(): number`
    - `tokenCount(path: string): number`
    - `score(query: string): Array<{ path: string; score: number }>`

**BM25 (comment in `bm25.ts`):** Okapi `k1=1.2`, `b=0.75`;  
`idf(t) = ln(1 + (N - df + 0.5) / (df + 0.5))`;  
per-term: `idf * (tf*(k1+1)) / (tf + k1*(1-b+b*|d|/avgdl))`.

**Score rules:** same tokenizer; unique query terms; sum contributions; omit zeros; sort score desc, path asc tie-break; empty query → `[]`.

### Task 7: `syncCanonIndex` (hash diff → full rebuild)

**Files:**
- Create: `src/index/sync.ts`
- Test: `tests/index-sync.test.ts`

**Interfaces:**
- Consumes: `listCanonMarkdown`, `contentHash`, `tokenize` (via Bm25 + token_count), `Bm25Index.build`, `saveIndexPair`, `tryLoadManifest`, `loadIndexPair` (for repair path), `canonDir`, `randomUUID`
- Produces:
  - `syncCanonIndex(root: string): Promise<{ status: "fresh" | "updated"; indexed: number; changed: string[] }>`
  - Missing `docs/canon/` → throw (CLI maps to exit ≠0)
  - Missing/bad artifacts → treat as empty corpus baseline and rebuild
  - No hash diff → `{ status: "fresh", indexed: N, changed: [] }` without rewriting files
  - Diff → new `index_id` (`randomUUID()`), rebuild all docs, write pair, `{ status: "updated", indexed: N, changed: [...] }` where `changed` lists created/updated/deleted paths

```typescript
// tests/index-sync.test.ts
import assert from "node:assert/strict";
import { describe, it, beforeEach, afterEach } from "node:test";
import fs from "node:fs";
import os from "node:os";
import path from "node:path";
import { syncCanonIndex } from "../src/index/sync.js";
import { bm25IndexPath, indexManifestPath } from "../src/index/paths.js";
import { loadIndexPair } from "../src/index/io.js";

function writeCanon(root: string, rel: string, body: string): void {
  const abs = path.join(root, rel);
  fs.mkdirSync(path.dirname(abs), { recursive: true });
  fs.writeFileSync(abs, body);
}

describe("syncCanonIndex", () => {
  let root: string;
  beforeEach(() => {
    root = fs.mkdtempSync(path.join(os.tmpdir(), "doc-canon-sync-"));
    writeCanon(root, "docs/canon/a.md", "alpha beta");
  });
  afterEach(() => fs.rmSync(root, { recursive: true, force: true }));

  it("creates both artifacts with matching index_id", async () => {
    const first = await syncCanonIndex(root);
    assert.equal(first.status, "updated");
    assert.equal(first.indexed, 1);
    assert.ok(fs.existsSync(indexManifestPath(root)));
    assert.ok(fs.existsSync(bm25IndexPath(root)));
    const pair = loadIndexPair(root);
    assert.equal(pair.manifest.index_id, pair.bm25.index_id);
  });

  it("returns fresh without rewriting when unchanged", async () => {
    await syncCanonIndex(root);
    const before = fs.readFileSync(indexManifestPath(root), "utf8");
    const second = await syncCanonIndex(root);
    assert.equal(second.status, "fresh");
    assert.equal(fs.readFileSync(indexManifestPath(root), "utf8"), before);
  });

  it("rebuilds on edit with new index_id", async () => {
    await syncCanonIndex(root);
    const id1 = loadIndexPair(root).manifest.index_id;
    writeCanon(root, "docs/canon/a.md", "alpha beta gamma");
    const third = await syncCanonIndex(root);
    assert.equal(third.status, "updated");
    assert.ok(third.changed.includes("docs/canon/a.md"));
    assert.notEqual(loadIndexPair(root).manifest.index_id, id1);

    fs.unlinkSync(path.join(root, "docs/canon/b.md"));
    const r = await syncCanonIndex(root);
    assert.equal(r.status, "updated");
    assert.ok(r.changed.includes("docs/canon/b.md"));
    assert.equal(loadIndexPair(root).manifest.docs["docs/canon/b.md"], undefined);
  });

  it("repairs corrupt bm25 on next sync", async () => {
    await syncCanonIndex(root);
    fs.writeFileSync(bm25IndexPath(root), "{not-json");
    const r = await syncCanonIndex(root);
    assert.equal(r.status, "updated");
    assert.ok(loadIndexPair(root).manifest.index_id);
```

```typescript
// src/index/reader.ts
import fs from "node:fs";
import path from "node:path";
import { Bm25Index } from "./bm25.js";
import { contentHash } from "./hash.js";
import { loadIndexPair } from "./io.js";
import { listCanonMarkdown } from "./list.js";
import type { IndexManifest } from "./types.js";

export type CanonIndexHandle = {
  score(query: string): Array<{ path: string; score: number }>;
  manifest: IndexManifest;
  liveHashes(): Record<string, string>;
};

export function openCanonIndex(root: string): CanonIndexHandle {
  const { manifest, bm25 } = loadIndexPair(root);
  const index = Bm25Index.fromJSON(bm25);
  return {
    score: (query) => index.score(query),
    manifest,
    liveHashes: () => {
      const out: Record<string, string> = {};
      for (const rel of listCanonMarkdown(root)) {
        const abs = path.join(root, ...rel.split("/"));
        out[rel] = contentHash(fs.readFileSync(abs, "utf8"));
      }
      return out;
    },
  };
}
```

```typescript
// src/index/watch.ts (shape)
import { syncCanonIndex } from "./sync.js";
import { acquireWatchPid, releaseWatchPid } from "./pid-lock.js";

export async function watchCanonIndex(
  root: string,
  intervalMs: number,
): Promise<number> {
  acquireWatchPid(root);
  let timer: NodeJS.Timeout | undefined;
  const shutdown = () =>
    new Promise<number>((resolve) => {
      if (timer) clearInterval(timer);
      releaseWatchPid(root);
      resolve(0);
    });

  process.on("SIGINT", () => {
    void shutdown().then((code) => process.exit(code));
  });
  process.on("SIGTERM", () => {
    void shutdown().then((code) => process.exit(code));
  });

  try {
    const first = await syncCanonIndex(root);
    if (first.status === "updated") {
      console.log(`index updated: ${first.indexed} docs`);
    }
  } catch (e) {
    releaseWatchPid(root);
    console.error(`error: ${e instanceof Error ? e.message : String(e)}`);
    return 1;
  }

  await new Promise<void>((resolve) => {
    timer = setInterval(() => {
      void (async () => {
        try {
          const r = await syncCanonIndex(root);
          if (r.status === "updated") {
            console.log(
              `index updated: ${r.indexed} docs (changed: ${r.changed.length})`,
            );
          }
        } catch (e) {
          const msg = e instanceof Error ? e.message : String(e);
          if (/docs\/canon not found/i.test(msg)) {
            if (timer) clearInterval(timer);
            releaseWatchPid(root);
            console.error(`error: ${msg}`);
            process.exitCode = 1;
            resolve();
            return;
          }
          console.error(`error: ${msg}`);
        }
      })();
    }, intervalMs);
  });

  return process.exitCode === 1 ? 1 : 0;
}
```

Prefer a cleaner Promise that resolves on signal without double `process.exit` if tests need it — keep signal → release lock as the invariant.

Wire in `indexCanon`: parse interval, call `watchCanonIndex`.

`stopWatchPid`: if alive, `process.kill(pid, "SIGTERM")`; remove pid file; return `{ stopped: true, pid }`.
