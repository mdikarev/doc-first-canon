# Future plans

Draft long-term initiatives for post-MVP work. **Not** behavioral source of truth — living product rules stay in the root canon files (`OVERVIEW`, `ARCHITECTURE`, `CLI`, `SKILLS`, …).

## How to use

1. Refine one initiative at a time in a dedicated brainstorming session (`draft` → `refining`).
2. Build `docs/roadmap/` / executable tasks only after that refinement (later).
3. After implementation, absorb outcomes into normal canon sections and mark the initiative `absorbed` (or remove it).

Design rationale: [`docs/superpowers/specs/2026-08-09-production-path-roadmap-design.md`](../../superpowers/specs/2026-08-09-production-path-roadmap-design.md).

## Status vocabulary

| Status | Meaning |
| --- | --- |
| `draft` | Captured; not refined |
| `refining` | Active brainstorming / design |
| `implementing` | Build in progress |
| `absorbed` | Outcomes merged into living canon |
